# Ordenação Parcial em C#

Projeto desenvolvido na disciplina de **Algoritmos e Estruturas de Dados**, com foco na implementação e comparação de algoritmos de ordenação parcial.

## Algoritmos implementados

- Selection Sort Parcial
- Insertion Sort Parcial
- QuickSort Parcial
- HeapSort Parcial

## Funcionalidades

O programa permite:

- definir o tamanho do vetor;
- escolher o tipo de vetor: crescente, decrescente ou aleatório;
- informar o valor de K;
- selecionar os menores ou maiores elementos;
- escolher o algoritmo de ordenação parcial;
- visualizar o vetor original e o resultado;
- medir o tempo de execução.

## Tecnologias

- C#
- .NET
- Visual Studio Code
